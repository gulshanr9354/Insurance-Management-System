# 🛡️ Insurance Management System

A full-stack Insurance Management System built using the MERN Stack (MongoDB, Express.js, React, Node.js). The application helps insurance companies manage customers, policies, claims, payments, and reports through a secure and user-friendly dashboard.

---

## 📌 Features

### 🔐 Authentication
- User Registration
- User Login
- JWT Authentication
- Protected Routes
- Logout Functionality

### 👥 Customer Management
- Add Customer
- Update Customer
- Delete Customer
- View Customer List

### 📄 Policy Management
- Create Insurance Policy
- Edit Policy
- Delete Policy
- Assign Policy to Customers

### 📋 Claims Management
- Register New Claims
- Update Claim Status
- Delete Claims
- View Claims

### 💳 Payment Management
- Record Premium Payments
- Update Payment Status
- Delete Payments
- Payment History

### 📊 Reports Dashboard
- Total Customers
- Total Policies
- Total Claims
- Total Revenue
- Interactive Charts using Chart.js

### 📤 Export Features
- Export Reports to PDF
- Export Reports to Excel

### 🎨 UI Features
- Responsive Dashboard
- Beautiful Landing Page
- Toast Notifications
- Sidebar Navigation
- Modern Cards & Charts

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/Insurance-Management-System.git
```

---

## Install Frontend

```bash
cd client
npm install
```

---

## Install Backend

```bash
cd ../server
npm install
```

---

# ▶️ Run the Application

### Start Backend

```bash
cd server
npm start
```

or

```bash
npm run dev
```

---

### Start Frontend

```bash
cd client
npm run dev
```

---

# 🌐 Default URLs

Frontend


Backend

# 🔑 Environment Variables

Create a `.env` file inside the `server` folder.

```env
PORT=5000

MONGO_URI=Your_MongoDB_Connection_String

JWT_SECRET=YourSecretKey
```
